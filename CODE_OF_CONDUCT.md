# Code of Conduct

OBS Gamepad Hotkeys welcomes respectful participation from users, testers, contributors, and maintainers.

## Expected behavior

- Be clear, constructive, and respectful.
- Focus criticism on code, behavior, documentation, or process—not on people.
- Assume good intent while still being precise about technical risk.
- Keep bug reports reproducible and discussions relevant to the project.
- Respect privacy. Do not publish credentials, personal information, private logs, or security-sensitive details.
- Give credit for contributions and third-party work where appropriate.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, deliberate disruption, spam, doxxing, or publishing sensitive information without permission are not acceptable.

## Project moderation

Maintainers may edit, hide, lock, or remove content that violates these expectations, and may restrict participation when necessary to keep the project safe and productive.

For security-sensitive matters, use the process in [SECURITY.md](SECURITY.md) rather than a public discussion.

## Scope

This code of conduct applies to project spaces managed by this repository, including issues, pull requests, reviews, and related project discussions.
