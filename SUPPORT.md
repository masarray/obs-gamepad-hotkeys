# Support

For normal setup and usage, start with the [README](README.md) and the public [landing page](https://masarray.github.io/obs-gamepad-hotkeys/).

## Before opening an issue

Please check these first:

- restart OBS after installing or updating the plugin;
- open **Tools → Gamepad Hotkeys** and confirm the plugin UI appears;
- use **Listen** to confirm the controller button is detected;
- try **Any Controller** before a device-specific mapping;
- click the refresh icon if a newly installed OBS plugin action is missing;
- for ArZoom, confirm the ArZoom filter is installed and attached to a Display Capture source;
- download installers only from the official GitHub Releases page.

## Bug reports

A useful bug report includes:

- OBS Studio version;
- Windows version;
- OBS Gamepad Hotkeys version;
- controller brand/model and whether it is XInput or DirectInput if known;
- whether **Tools → Gamepad Hotkeys** appears;
- whether **Listen** detects the button;
- the OBS action or ArZoom action being mapped;
- exact steps to reproduce the problem;
- what you expected and what actually happened.

If an OBS log is relevant, remove unrelated personal paths or private information before attaching it.

## Feature requests

Explain the workflow you are trying to improve, not only the UI control or implementation you want added. This makes it easier to find a solution that remains native, lightweight, and compatible with OBS.

## Security reports

Do not post vulnerability details publicly. Follow [SECURITY.md](SECURITY.md).

## What support cannot guarantee

This is an independent open-source project. Hardware combinations, third-party OBS plugins, custom OBS builds, corporate endpoint policies, and future OBS versions may behave differently. Reports with clear reproduction details are the fastest path to a reliable fix.
