Windows safety, explained clearly

SmartScreen may ask for confirmation.
That is expected on the current preview.

The current v0.1.5 installer is unsigned. Microsoft Defender SmartScreen uses publisher reputation and file reputation when evaluating downloaded apps, so a new or unsigned open-source installer can show Windows protected your PC or Unknown Publisher.

1. Use the official source

Download only from this website or the project's official GitHub Release. Both point to the same release asset.

2. A checksum is published

Every installer is shipped with a SHA-256 checksum file so you can verify the exact download.

Open installer checksum →
3. Keep Windows protection on

We never ask you to disable Defender or SmartScreen. If Windows offers More info → Run anyway, use it only after you trust the official source.

A SmartScreen reputation warning is not the same as a malware detection.

If Smart App Control or a company policy blocks the installer completely, do not bypass that policy. Use an allowed machine, ask your IT administrator, or wait for a signed release.

Common questions

Know what to expect
before you need help.

I installed it. Where do I open it?+

Restart OBS after installation, then open Tools → Gamepad Hotkeys. That window shows detected controllers, mappings and the last controller input.

Will it work while my game is in the foreground?+

Yes — that is the main purpose. Controller input is read through native Windows controller APIs instead of relying on a keyboard shortcut reaching OBS.

Will OBS steal the controller button from my game?+

No. Input is non-exclusive. If the game also uses that button, both the game and OBS can react. Pick a mapping that fits your game's controls.

Which controllers are supported?+

Xbox-compatible XInput controllers are supported, plus many generic USB gamepads and joysticks through DirectInput. The current release is Windows x64 only.

Do I still need JoyToKey?+

No. There is no JoyToKey or synthetic keyboard shortcut in the control path.

Listen does not detect my gamepad. What should I try?+

First confirm the controller works in Windows or your game. Then reconnect it, leave the Gamepad Hotkeys window open for a moment, and try Any Controller. Generic DirectInput devices are rescanned automatically.

B does not pause recording. Is it broken?+

B pauses or resumes an active recording. Press START first to begin recording, then use B to pause and resume.

Why does Windows show Unknown Publisher?+

The current v0.1.5 public preview is unsigned, so SmartScreen may not have a trusted publisher identity to evaluate. Download only from the official release, use the published SHA-256 checksum for an extra integrity check, and never disable Windows security just to install the plugin.

I still need help. What should I send?+

Open a GitHub Issue and include your OBS version, controller model, whether Tools → Gamepad Hotkeys appears, whether Listen detects the button, and which OBS action you tried. Those details make troubleshooting much faster.
