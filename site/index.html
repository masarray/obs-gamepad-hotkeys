Questions, answered

Before you install.

Will it work while my game is in the foreground?+

That is the core use case. The plugin uses native controller APIs and DirectInput background + non-exclusive mode rather than relying on a keyboard shortcut reaching OBS.

Will OBS steal the controller button from my game?+

No. Input is intentionally non-exclusive. If the game also uses that button, both the game and OBS can react, so choose mappings that fit your control scheme.

Which controllers are supported?+

Windows XInput controllers are supported, including Xbox-compatible pads, plus generic USB gamepads and joysticks through DirectInput. The current release is Windows x64 only.

Do I still need JoyToKey?+

No. OBS Gamepad Hotkeys reads the controller directly and routes mappings to OBS natively. JoyToKey and keyboard emulation are not part of the control path.

Why might Windows show an Unknown Publisher warning?+

Windows SmartScreen and publisher reputation are separate from installer UX. A build that is not Authenticode-signed by a trusted certificate may still show a publisher warning. Checksums are published alongside every release asset.
